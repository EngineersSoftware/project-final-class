## Cómo ver los diagramas

Los archivos usan [Mermaid](https://mermaid.js.org/). Para previsualizarlos en Cursor o VS Code:

1. Abre cualquier archivo `.md` de esta carpeta.
2. Abre la vista previa con `Ctrl+Shift+V` (o clic derecho → **Open Preview**).
3. Si los diagramas no se renderizan, instala la extensión **Markdown Preview Mermaid Support**.

También puedes verlos directamente en GitHub al abrir los archivos en el repositorio.
